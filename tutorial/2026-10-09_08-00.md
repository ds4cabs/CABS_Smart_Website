# Question
How can we utilize machine learning techniques in Python to predict protein secondary structure from amino acid sequences?

# Solution

## Step 1: Data Preparation
We will use the CB513 dataset, which contains sequences and their corresponding secondary structure annotations. 
First, we need to install necessary libraries and load the data.

```bash
pip install pandas scikit-learn
```

```python
import pandas as pd

# Load the dataset
data = pd.read_csv('cb513.csv')  # replace with the actual file path
print(data.head())
```

## Step 2: Feature Extraction
We will convert amino acid sequences into numerical features using one-hot encoding.

```python
from sklearn.preprocessing import OneHotEncoder
import numpy as np

def one_hot_encode(sequence):
    aa_dict = {aa: idx for idx, aa in enumerate('ACDEFGHIKLMNPQRSTVWY')}
    one_hot = np.zeros((len(sequence), 20))
    for i, aa in enumerate(sequence):
        if aa in aa_dict:
            one_hot[i][aa_dict[aa]] = 1
    return one_hot.flatten()

# Example sequence
sequence = 'ACDEFGHIK'
encoded = one_hot_encode(sequence)
print(encoded)
```

## Step 3: Prepare Labels
Convert secondary structure labels into a categorical format.

```python
def preprocess_labels(labels):
    return labels.map({'H': 0, 'E': 1, 'C': 2}).values  # Helix, Sheet, Coil

# Example labels
labels = ['H', 'E', 'C', 'C', 'H']
encoded_labels = preprocess_labels(labels)
print(encoded_labels)
```

## Step 4: Split the Data
Split the dataset into training and testing sets.

```python
from sklearn.model_selection import train_test_split

X = data['sequence'].apply(one_hot_encode)
y = preprocess_labels(data['secondary_structure'])

X_train, X_test, y_train, y_test = train_test_split(np.vstack(X), y, test_size=0.2, random_state=42)
```

## Step 5: Build a Model
Next, we will create a simple Neural Network using Keras.

```bash
pip install tensorflow
```

```python
from tensorflow import keras
from tensorflow.keras import layers

model = keras.Sequential([
    layers.Input(shape=(X_train.shape[1],)),
    layers.Dense(128, activation='relu'),
    layers.Dense(64, activation='relu'),
    layers.Dense(3, activation='softmax')  # Output layer for 3 classes
])

model.compile(optimizer='adam', 
              loss='sparse_categorical_crossentropy', 
              metrics=['accuracy'])
```

## Step 6: Train the Model
Now, we can train our model.

```python
history = model.fit(X_train, y_train, epochs=10, batch_size=32, validation_split=0.2)
```

## Step 7: Evaluate the Model
Evaluate the model on the test data.

```python
test_loss, test_accuracy = model.evaluate(X_test, y_test)
print(f'Test Accuracy: {test_accuracy:.2f}')
```

## Step 8: Make Predictions
Finally, we can use the trained model to make predictions.

```python
predictions = model.predict(X_test)
predicted_classes = np.argmax(predictions, axis=1)
print(predicted_classes)
```

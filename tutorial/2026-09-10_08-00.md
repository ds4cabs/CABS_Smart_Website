# How Can We Use Python to Perform DNA Sequence Analysis with Machine Learning?

## Problem Statement

In bioinformatics, DNA sequence analysis is crucial for understanding genetic information. This tutorial demonstrates how to use Python's scikit-learn library to classify DNA sequences as either 'gene' or 'non-gene' based on features extracted from the sequences.

## Solution

### Step 1: Installing Necessary Libraries

```bash
pip install numpy pandas scikit-learn
```

### Step 2: Import Required Libraries

```python
import numpy as np
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.feature_extraction.text import CountVectorizer
from sklearn.naive_bayes import MultinomialNB
from sklearn.metrics import accuracy_score, classification_report
```

### Step 3: Prepare the Dataset

```python
# Sample Data: DNA sequences labeled as gene (1) or non-gene (0).
data = {
    'sequence': [
        'ATGCGTA', 'ATCGTAC', 'CGTACGT', 'TTAGCCT', 
        'CGTAGCT', 'TTGAGCT', 'TACGTAG', 'GCGATCG'
    ],
    'label': [1, 1, 1, 0, 1, 0, 0, 0]
}

df = pd.DataFrame(data)
print(df.head())
```

### Step 4: Feature Extraction

```python
# Convert DNA sequences into a matrix of token counts
vectorizer = CountVectorizer(analyzer='char', ngram_range=(1, 2))
X = vectorizer.fit_transform(df['sequence']).toarray()
y = df['label']
```

### Step 5: Split the Data

```python
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.25, random_state=42)
```

### Step 6: Train the Model

```python
# Initialize and train the Naive Bayes classifier
model = MultinomialNB()
model.fit(X_train, y_train)
```

### Step 7: Make Predictions

```python
y_pred = model.predict(X_test)
```

### Step 8: Evaluate the Model

```python
# Check the accuracy of the model
accuracy = accuracy_score(y_test, y_pred)
print(f'Accuracy: {accuracy:.2f}')

# Detailed classification report
print(classification_report(y_test, y_pred))
```

### Conclusion

The above Python code provides a simple yet effective way to classify DNA sequences using machine learning techniques. This approach lays the foundation for more complex models and larger datasets in bioinformatics research.

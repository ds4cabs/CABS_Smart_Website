# Question: How to Use Machine Learning for Predicting Gene Expression Levels from Sequence Data in Python?

## Solution:

In this tutorial, we will predict gene expression levels using a machine learning model based on DNA sequence data. We'll use Python and libraries like `pandas`, `scikit-learn`, and `numpy`.

### Step 2: Import Libraries

```python
import pandas as pd
import numpy as np
from sklearn.model_selection import train_test_split
from sklearn.ensemble import RandomForestRegressor
from sklearn.metrics import mean_squared_error
```

### Step 3: Load the Dataset

Assume we have a dataset `gene_expression.csv` with columns `sequence` and `expression_level`.

```python
data = pd.read_csv('gene_expression.csv')
print(data.head())
```

### Step 4: Feature Engineering

Convert DNA sequences to numerical features using one-hot encoding.

```python
def one_hot_encode(sequence):
    encoding = np.zeros((len(sequence), 4))
    mapping = {'A': 0, 'C': 1, 'G': 2, 'T': 3}
    for i, nucleotide in enumerate(sequence):
        if nucleotide in mapping:
            encoding[i, mapping[nucleotide]] = 1
    return encoding.flatten()

# Apply one-hot encoding
features = np.array([one_hot_encode(seq) for seq in data['sequence']])
labels = data['expression_level'].values
```

### Step 5: Split the Data

Split the dataset into training and testing sets.

```python
X_train, X_test, y_train, y_test = train_test_split(features, labels, test_size=0.2, random_state=42)
```

### Step 6: Train the Model

Use a random forest regressor to fit the training data.

```python
model = RandomForestRegressor(n_estimators=100, random_state=42)
model.fit(X_train, y_train)
```

### Step 7: Make Predictions

Predict gene expression on the test set.

```python
y_pred = model.predict(X_test)
```

### Step 8: Evaluate the Model

Evaluate the model's performance using Mean Squared Error (MSE).

```python
mse = mean_squared_error(y_test, y_pred)
print(f'Mean Squared Error: {mse}')
```

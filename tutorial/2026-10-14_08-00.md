# Solution

### Step 1: Load and Preprocess Genomic Data
We will use the Biopython library to load genomic sequences from a FASTA file.

```python
from Bio import SeqIO
import pandas as pd

# Load genomic sequences
def load_sequences(fasta_file):
    sequences = []
    for record in SeqIO.parse(fasta_file, "fasta"):
        sequences.append(str(record.seq))
    return sequences

fasta_file = "example_genomes.fasta"
genomic_sequences = load_sequences(fasta_file)
print(genomic_sequences)
```

### Step 2: Encode Sequences
We will convert DNA sequences into a format that can be fed into a machine learning model by encoding them.

```python
import numpy as np

def encode_sequences(sequences):
    encoding = {'A': [1, 0, 0, 0], 'C': [0, 1, 0, 0], 'G': [0, 0, 1, 0], 'T': [0, 0, 0, 1]}
    encoded_sequences = []
    
    for seq in sequences:
        encoded = []
        for nucleotide in seq:
            encoded.extend(encoding[nucleotide])
        encoded_sequences.append(encoded)
    
    return np.array(encoded_sequences)

encoded_data = encode_sequences(genomic_sequences)
print(encoded_data)
```

### Step 3: Build a Neural Network Model
We will create a neural network model using TensorFlow to predict protein functions.

```python
import tensorflow as tf
from tensorflow.keras import layers

# Create the model
def create_model(input_shape):
    model = tf.keras.Sequential([
        layers.Dense(128, activation='relu', input_shape=(input_shape,)),
        layers.Dense(64, activation='relu'),
        layers.Dense(32, activation='relu'),
        layers.Dense(1, activation='sigmoid')  # Assuming binary classification
    ])
    model.compile(optimizer='adam', loss='binary_crossentropy', metrics=['accuracy'])
    return model

model = create_model(encoded_data.shape[1])
model.summary()
```

### Step 4: Train the Model
You will need labeled data to train the model. For simplicity, we assume `labels` is a binary list of protein functions.

```python
# Dummy labels (replace with actual labels)
labels = np.random.randint(0, 2, size=(encoded_data.shape[0]))

# Train the model
model.fit(encoded_data, labels, epochs=10, batch_size=32, validation_split=0.2)
```

### Step 5: Predictions
Finally, make predictions on new genomic sequences.

```python
def predict_functions(model, new_sequences):
    new_encoded_data = encode_sequences(new_sequences)
    predictions = model.predict(new_encoded_data)
    return predictions

new_genomic_sequences = ["ATCG", "GCTA"]  # Example new sequences
predictions = predict_functions(model, new_genomic_sequences)
print(predictions)
```

# Question
How can we use Python to perform sequence alignment in bioinformatics, specifically using the Needleman-Wunsch algorithm?

# Solution

## Introduction
The Needleman-Wunsch algorithm is a dynamic programming algorithm used for global sequence alignment. It is commonly used in bioinformatics to align protein or nucleotide sequences.

### Requirements
Make sure you have the `numpy` library installed. You can install it using pip:

```bash
pip install numpy
```

## Implementation

```python
import numpy as np

def needleman_wunsch(seq1, seq2, match_score=1, mismatch_score=-1, gap_score=-1):
    # Initialize scoring matrix
    n, m = len(seq1), len(seq2)
    score_matrix = np.zeros((n + 1, m + 1))

    # Fill the first row and first column
    for i in range(n + 1):
        score_matrix[i][0] = gap_score * i
    for j in range(m + 1):
        score_matrix[0][j] = gap_score * j

    # Fill in the scoring matrix
    for i in range(1, n + 1):
        for j in range(1, m + 1):
            match = score_matrix[i - 1][j - 1] + (match_score if seq1[i - 1] == seq2[j - 1] else mismatch_score)
            delete = score_matrix[i - 1][j] + gap_score
            insert = score_matrix[i][j - 1] + gap_score
            score_matrix[i][j] = max(match, delete, insert)

    # Traceback
    align_seq1 = ""
    align_seq2 = ""
    i, j = n, m

    while i > 0 and j > 0:
        if score_matrix[i][j] == score_matrix[i - 1][j - 1] + (match_score if seq1[i - 1] == seq2[j - 1] else mismatch_score):
            align_seq1 += seq1[i - 1]
            align_seq2 += seq2[j - 1]
            i -= 1
            j -= 1
        elif score_matrix[i][j] == score_matrix[i - 1][j] + gap_score:
            align_seq1 += seq1[i - 1]
            align_seq2 += '-'
            i -= 1
        else:
            align_seq1 += '-'
            align_seq2 += seq2[j - 1]
            j -= 1

    while i > 0:
        align_seq1 += seq1[i - 1]
        align_seq2 += '-'
        i -= 1

    while j > 0:
        align_seq1 += '-'
        align_seq2 += seq2[j - 1]
        j -= 1

    return align_seq1[::-1], align_seq2[::-1], score_matrix[n][m]

# Example Usage
if __name__ == "__main__":
    sequence1 = "AGTACGCA"
    sequence2 = "TAGACCA"
    aligned_seq1, aligned_seq2, score = needleman_wunsch(sequence1, sequence2)
    print("Alignment 1: ", aligned_seq1)
    print("Alignment 2: ", aligned_seq2)
    print("Alignment Score: ", score)
```

### Explanation
1. **Initialization**: Define a scoring matrix and initialize gap penalties.
2. **Matrix Filling**: Compute scores based on matches, mismatches, and gaps.
3. **Traceback**: Recover the aligned sequences from the scoring matrix.
4. **Output**: Display the aligned sequences and the final alignment score.

### Example Output
```

Alignment 2:  TA-G-ACCA
Alignment Score:  3
```

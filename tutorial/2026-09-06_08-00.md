# Advanced AI in Bioinformatics: Predicting Protein Secondary Structures

## Question
How can we use machine learning to predict the secondary structure of proteins from their amino acid sequences?

## Solution

In this tutorial, we will use Python to implement a simple neural network to predict protein secondary structures using the `Keras` library alongside `NumPy` and `Pandas`. We'll work with the well-known CB513 dataset for this task.

### Prerequisites
Make sure you have the following libraries installed:
```bash
pip install pandas numpy keras tensorflow scikit-learn
```

### Step 1: Import Libraries
```python
import pandas as pd
import numpy as np
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import OneHotEncoder
from tensorflow.keras.models import Sequential
from tensorflow.keras.layers import Dense, LSTM, Embedding, Dropout
```

### Step 2: Load and Prepare the Data
```python
# Load the CB513 dataset
data = pd.read_csv('cb513.csv')  # replace with your actual dataset path

# Assume the dataset has columns `sequence` and `structure`
sequences = data['sequence'].values
structures = data['structure'].values

# One-hot encode the structure labels
encoder = OneHotEncoder()
structures_encoded = encoder.fit_transform(structures.reshape(-1, 1)).toarray()

# Split the dataset
X_train, X_test, y_train, y_test = train_test_split(sequences, structures_encoded, test_size=0.2, random_state=42)
```

### Step 3: Preprocess the Sequences
```python
def amino_acid_to_index(sequence):
    amino_acids = 'ACDEFGHIKLMNPQRSTVWY'
    return [amino_acids.index(aa) for aa in sequence]

X_train_processed = np.array([amino_acid_to_index(seq) for seq in X_train])
X_test_processed = np.array([amino_acid_to_index(seq) for seq in X_test])

# Padding sequences
from tensorflow.keras.preprocessing.sequence import pad_sequences
max_length = max(len(seq) for seq in X_train_processed)
X_train_padded = pad_sequences(X_train_processed, maxlen=max_length)
X_test_padded = pad_sequences(X_test_processed, maxlen=max_length)
```

### Step 4: Build and Compile the Model
```python
model = Sequential()
model.add(Embedding(input_dim=20, output_dim=64, input_length=max_length))  # 20 amino acids
model.add(LSTM(128, return_sequences=True))
model.add(Dropout(0.5))
model.add(Dense(len(encoder.categories_[0]), activation='softmax'))

model.compile(loss='categorical_crossentropy', optimizer='adam', metrics=['accuracy'])
```

### Step 5: Train the Model
```python
model.fit(X_train_padded, y_train, batch_size=32, epochs=20, validation_split=0.2)
```

### Step 6: Evaluate the Model
```python
loss, accuracy = model.evaluate(X_test_padded, y_test)
print(f'Test Loss: {loss}, Test Accuracy: {accuracy}')
```

# Tutorial: Using Python for Gene Sequence Analysis with Advanced AI Techniques

## Question
How can we perform gene sequence classification using a pre-trained machine learning model in Python?

## Solution

In this tutorial, we will demonstrate how to use Python to classify gene sequences based on their features leveraging a pre-trained machine learning model.

### Step 1: Install Required Libraries

Ensure you have the necessary libraries installed. You can use pip to install them:

```bash
pip install numpy pandas scikit-learn biopython
```

### Step 2: Import Libraries

```python
import pandas as pd
import numpy as np
from sklearn.model_selection import train_test_split
from sklearn.ensemble import RandomForestClassifier
from sklearn.metrics import classification_report
from Bio import SeqIO
```

### Step 3: Load Gene Sequences

Load your gene sequences from a FASTA file using `Biopython`.

```python
def load_sequences(fasta_file):
    sequences = []
    for record in SeqIO.parse(fasta_file, "fasta"):
        sequences.append(str(record.seq))
    return sequences

# Example usage
gene_sequences = load_sequences("path/to/your/sequences.fasta")
```

### Step 4: Feature Extraction

We will convert the DNA sequences into a numerical format suitable for classification.

```python
def extract_features(sequences):
    feature_matrix = []
    for seq in sequences:
        # Example: Calculate GC content and sequence length
        gc_content = (seq.count('G') + seq.count('C')) / len(seq)
        feature_matrix.append([gc_content, len(seq)])
    return np.array(feature_matrix)

# Example usage
features = extract_features(gene_sequences)
```

### Step 5: Prepare Data for Training

Split the dataset into training and testing sets. In a real application, you would have labels for your gene sequences.

```python
# Simulate labels for the purpose of this example
labels = np.random.choice([0, 1], size=len(features))  # Binary classification
    
X_train, X_test, y_train, y_test = train_test_split(features, labels, test_size=0.2, random_state=42)
```

### Step 6: Train the Model

Train a Random Forest Classifier on the training data.

```python
model = RandomForestClassifier(n_estimators=100, random_state=42)
model.fit(X_train, y_train)
```

### Step 7: Evaluate the Model

Evaluate the model's performance on the test set.

```python
y_pred = model.predict(X_test)
print(classification_report(y_test, y_pred))
```

### Step 8: Make Predictions

You can now classify new gene sequences using the trained model.

```python
new_sequences = load_sequences("path/to/new/sequences.fasta")
new_features = extract_features(new_sequences)
predictions = model.predict(new_features)

for seq, pred in zip(new_sequences, predictions):
    print(f"Sequence: {seq[:30]}... Predicted Class: {pred}")
```

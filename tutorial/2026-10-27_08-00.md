# Question: How to Implement a Sequence Alignment Algorithm in Python for Bioinformatics?

## Solution

In bioinformatics, sequence alignment is a fundamental method used to identify similarities between biological sequences, such as DNA, RNA, or protein sequences. Here we will implement the Needleman-Wunsch algorithm, a widely used method for global alignment of sequences.

### Step 2: Implement the Needleman-Wunsch Algorithm

```python
import numpy as np

def create_score_matrix(seq1, seq2, match=1, mismatch=-1, gap=-2):
    # Initialize the score matrix
    m, n = len(seq1), len(seq2)
    score_matrix = np.zeros((m + 1, n + 1))

    # Fill the first row and first column
    for i in range(m + 1):
        score_matrix[i][0] = gap * i
    for j in range(n + 1):
        score_matrix[0][j] = gap * j

    # Fill the score matrix
    for i in range(1, m + 1):
        for j in range(1, n + 1):
            match_score = (score_matrix[i - 1][j - 1] + (match if seq1[i - 1] == seq2[j - 1] else mismatch))
            delete_score = score_matrix[i - 1][j] + gap
            insert_score = score_matrix[i][j - 1] + gap
            score_matrix[i][j] = max(match_score, delete_score, insert_score)

    return score_matrix

def traceback(score_matrix, seq1, seq2, gap=-2):
    alignment_a, alignment_b = "", ""
    i, j = score_matrix.shape[0] - 1, score_matrix.shape[1] - 1

    while i > 0 or j > 0:
        current_score = score_matrix[i][j]
        
        if i > 0 and j > 0 and current_score == score_matrix[i - 1][j - 1] + (1 if seq1[i - 1] == seq2[j - 1] else -1):
            alignment_a += seq1[i - 1]
            alignment_b += seq2[j - 1]
            i -= 1
            j -= 1
        elif i > 0 and current_score == score_matrix[i - 1][j] + gap:
            alignment_a += seq1[i - 1]
            alignment_b += "-"
            i -= 1
        elif j > 0 and current_score == score_matrix[i][j - 1] + gap:
            alignment_a += "-"
            alignment_b += seq2[j - 1]
            j -= 1
    
    return alignment_a[::-1], alignment_b[::-1]

def needleman_wunsch(seq1, seq2):
    score_matrix = create_score_matrix(seq1, seq2)
    alignment_a, alignment_b = traceback(score_matrix, seq1, seq2)
    return alignment_a, alignment_b

# Example usage
if __name__ == "__main__":
    seq1 = "AGCTG" 
    seq2 = "AGCT"
    aligned_seq1, aligned_seq2 = needleman_wunsch(seq1, seq2)
    print("Aligned Sequences:")
    print(aligned_seq1)
    print(aligned_seq2)
```

### Step 3: Explanation

1. **Score Matrix Creation**: The function `create_score_matrix` initializes a score matrix based on the provided sequences. It incorporates gap penalties and scoring for matches and mismatches.
   
2. **Traceback**: The `traceback` function constructs the aligned sequences by traversing back through the score matrix, deciding whether to match, insert a gap, or delete based on the scores.

3. **Execution**: The `needleman_wunsch` function ties everything together. When executed, it takes two sequences, computes their alignment, and prints the aligned results.

### Output

When the provided code is executed with the example sequences, the output will be:

```
Aligned Sequences:
AGCTG
AGCT-
```

The `-` represents a gap in the second sequence. This method provides a clear and systematic way to align sequences for analysis in bioinformatics.

# Question

How can we use Python to perform DNA sequence alignment using the Needleman-Wunsch algorithm, a dynamic programming approach, in bioinformatics?

# Solution

The Needleman-Wunsch algorithm is a classic algorithm used for optimal global alignment of two sequences. Here, we will implement this algorithm in Python to align two DNA sequences.

### Step-by-Step Implementation

```python
import numpy as np

def create_score_matrix(seq1, seq2, match=1, mismatch=-1, gap=-2):
    # Create score matrix
    n = len(seq1) + 1
    m = len(seq2) + 1
    score_matrix = np.zeros((n, m))

    # Initialize first column and first row
    for i in range(1, n):
        score_matrix[i][0] = gap * i
    for j in range(1, m):
        score_matrix[0][j] = gap * j

    # Fill the score matrix
    for i in range(1, n):
        for j in range(1, m):
            if seq1[i - 1] == seq2[j - 1]:
                match_score = score_matrix[i - 1][j - 1] + match
            else:
                match_score = score_matrix[i - 1][j - 1] + mismatch
            delete = score_matrix[i - 1][j] + gap
            insert = score_matrix[i][j - 1] + gap
            score_matrix[i][j] = max(match_score, delete, insert)

    return score_matrix

def traceback(score_matrix, seq1, seq2, gap="-"):
    align1, align2 = "", ""
    i, j = score_matrix.shape[0] - 1, score_matrix.shape[1] - 1

    while i > 0 and j > 0:
        current_score = score_matrix[i][j]
        diagonal_score = score_matrix[i - 1][j - 1]
        up_score = score_matrix[i][j - 1]
        left_score = score_matrix[i - 1][j]
        
        if current_score == diagonal_score + (1 if seq1[i - 1] == seq2[j - 1] else -1):
            align1 += seq1[i - 1]
            align2 += seq2[j - 1]
            i -= 1
            j -= 1
        elif current_score == left_score - 2:
            align1 += seq1[i - 1]
            align2 += gap
            i -= 1
        else:
            align1 += gap
            align2 += seq2[j - 1]
            j -= 1

    # Handle remaining residues
    while i > 0:
        align1 += seq1[i - 1]
        align2 += gap
        i -= 1
    while j > 0:
        align1 += gap
        align2 += seq2[j - 1]
        j -= 1

    return align1[::-1], align2[::-1]

def needleman_wunsch(seq1, seq2):
    score_matrix = create_score_matrix(seq1, seq2)
    align1, align2 = traceback(score_matrix, seq1, seq2)
    return align1, align2

# Example Usage
seq1 = "AGCTGTA"
seq2 = "GCTTAGA"

alignment = needleman_wunsch(seq1, seq2)
print("Sequence 1 Alignment:", alignment[0])
print("Sequence 2 Alignment:", alignment[1])
```

### Explanation

1. **Score Matrix Creation**: We define a function `create_score_matrix` to create a score matrix for the two sequences based on match, mismatch, and gap penalties.
   
2. **Matrix Filling**: The matrix is filled based on the scores derived from alignments (match, mismatch, insert, delete).
   
3. **Backtracking**: The `traceback` function is used to create aligned strings from the filled score matrix.

4. **Putting It All Together**: The `needleman_wunsch` function integrates the creation of the score matrix and the traceback process.
